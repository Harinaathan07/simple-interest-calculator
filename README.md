# Simple Interest Calculator

A simple script to calculate the simple interest given principal, annual rate of interest, and time period in years.

## Formula
Simple Interest = (P × T × R) / 100

Where:
- **P** = Principal amount
- **T** = Time period in years
- **R** = Annual rate of interest

## Inputs & Outputs
- **Input:** Principal (e.g., 1000), Time (e.g., 2), Rate (e.g., 5)
- **Output:** Simple Interest = 100
